### What we build

Marketing sites, portfolios, and content-driven sites for local businesses — built to
load fast, rank well, and stay easy to maintain. Static by default; we reach for a CMS
only when a client genuinely needs to manage their own content.

### How we build it

- **Stack** — Astro · TypeScript · Sanity · AWS Amplify
- **Performance & accessibility** — front of mind, with Lighthouse checks in the build
- **Quality gate** — every change ships through a CI pipeline (typecheck · lint · format · build)
- **Release flow** — a `staging → production` promotion model, so production is never a surprise
